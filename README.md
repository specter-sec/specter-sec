# IFTIKHAR

### Cybersecurity learner | Defensive security, SOC labs & Python tools

I build practical, defensive cybersecurity projects and beginner-friendly learning resources. Much of my work is local or offline-first: security tools, a Termux/Linux SOC lab, and Roman Urdu/Hinglish CTF material. I only test systems where I have explicit permission.

## Focus areas

- **Security operations:** [PocketSOC](https://github.com/specter-sec/pocketsoc) — a defensive monitoring and detection lab for Termux and Linux.
- **Developer security:** [LeakLens](https://github.com/specter-sec/leaklens) scans locally for likely secrets and produces redacted reports; [HashTrail](https://github.com/specter-sec/hashtrail) reviews local file-integrity snapshots.
- **Security education:** [CTF Urdu Hub](https://github.com/specter-sec/ctf-urdu-hub) offers beginner-friendly Roman Urdu/Hinglish learning notes and offline practice labs. [Open the live site](https://specter-sec.github.io/ctf-urdu-hub/).
- **Scam awareness:** [ScamGuard](https://github.com/specter-sec/scamguard) screens Urdu, Roman Urdu, and Hinglish messages for common scam patterns. A result is a warning, not a verdict.
- **Web security basics:** [WebGuard Lite](https://github.com/specter-sec/webguard-lite) passively checks common response headers on one URL.

## More projects

- [CyberAbroad](https://github.com/specter-sec/cyberabroad) — a source-linked explorer for cybersecurity study programs.
- [RepairDesk](https://github.com/specter-sec/repairdesk) — an offline-first repair-shop app.
- [RepairDB](https://github.com/specter-sec/repairdb) — a safety-first phone-repair learning reference; its examples are educational, not verified repair records.

## Principles

- Work only within an authorized scope.
- Prefer local, privacy-conscious tools where practical.
- Explain limitations clearly; a tool’s result is not proof that a system is secure.
